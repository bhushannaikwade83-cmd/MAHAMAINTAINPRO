================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Table already exists" error
Solution: This is OK! File has been run before. Safe to ignore.

Problem: "Foreign key error" or "Unknown column"
Solution: Did you run migration #1 before #2? They MUST run in order.

Problem: "Access denied" or "Unknown database"
Solution: Check username, password, database name are correct.
          Credentials: digitrix_maha_user / maha_user@70 / digitrix_maha_maintain_pro

Problem: Want to rollback/undo?
Solution: Restore from backup created in Step 1:
          mysql -u digitrix_maha_user -p digitrix_maha_maintain_pro < backup_YYYYMMDD_HHMMSS.sql
